## Reviewing a vendor

1. Read their latest security report or certification, if any. Note the date and scope.
2. Confirm the agreement is still in force and names their sub-processors.
3. Confirm what data they actually receive still matches the row.
4. Record the review date. Write the exit path if it is missing.
