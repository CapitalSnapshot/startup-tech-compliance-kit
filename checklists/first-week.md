# First week

Cheap items that remove the most risk. Aim to finish in a few days.

- [ ] Fill in [`../scoping/questionnaire.md`](../scoping/questionnaire.md) and write down the outcome you want (hygiene, questionnaires, or a framework foundation).
- [ ] Turn on MFA for every account that touches the company: cloud, code host, email, domain registrar, password manager.
- [ ] Put a second person (or a break-glass account held offline) on the cloud account and the domain.
- [ ] Move every secret you can find out of code and chat into a secrets manager.
- [ ] Turn on branch protection for the main branches: pull request required, checks required, no bypass.
- [ ] Turn on a secret scanner and a dependency scanner in the pipeline.
- [ ] Turn on automated database backups and disk snapshots.
- [ ] Turn on the cloud provider's audit trail.
- [ ] Start the vendor register and the secrets register (they can be a table in a file).
- [ ] Create the risk register and write down the five biggest gaps you know about.
- [ ] Write one page: who to call, and what to do first, if something goes wrong.
