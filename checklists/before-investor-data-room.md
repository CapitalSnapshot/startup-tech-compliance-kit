# Before an investor sees your data room

- [ ] The scoping questionnaire and applicability matrix are current, and you can say which frameworks and laws apply and which you are deliberately not pursuing.
- [ ] Every control in [`../controls/`](../controls/) has a dated evidence file, or an entry in the risk register with an owner and review date.
- [ ] You can show five recent production changes, each traced to a reviewed pull request and a green run.
- [ ] Your last restore-test report is less than a quarter old.
- [ ] The access review is less than a quarter old and every removal was acted on.
- [ ] The vendor register is complete and the data-processing agreements are on file.
- [ ] There are no secrets in the code history; the scanner has run over all of it.
- [ ] You can state in one paragraph where customer data lives, who can reach it, and how it is backed up.
- [ ] Anything you would rather not be asked about is in the risk register, with a plan.
- [ ] The data room contains evidence files, not claims.
- [ ] The risk register scores every risk, each has an owner and a treatment, and serious accepted risks were accepted by someone other than the owner.
- [ ] The privacy basics exist: data inventory, record of processing with lawful bases, retention rules, a tested deletion, and processor agreements.
- [ ] The evidence pack has been redacted and hashed ([`../evidence/handling.md`](../evidence/handling.md)).
