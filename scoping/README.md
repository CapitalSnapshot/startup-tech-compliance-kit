# Scoping

Do this first. It takes an hour and stops you building controls you do not need.

1. Fill in [`questionnaire.md`](questionnaire.md).
2. Read [`applicability-matrix.md`](applicability-matrix.md) against your answers.
3. If the questionnaire raises a regime outside the core (for example NIS2), use the matching screening aid in [`extensions/`](extensions/README.md). It records a decision; it does not assess compliance.
4. Write down the outcome you want (hygiene, questionnaires, or a framework foundation) and keep the answers with your evidence.
